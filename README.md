## Student Management System Using Java and MySQL LAB 1 
### Project Description
This project is a Java-based Student Management System that connects to a MySQL database using JDBC (Java Database Connectivity). It allows users to manage student records through basic database operations.

### Features
- View All Students: Retrieve and display all student records from the database.
- Add Student: Insert a new student record with name, age, department, and email.
- Update Student: Modify an existing student's information using their ID.
- Delete Student: Delete a student record using their ID.
- Search Student: Search for students by name using a partial or complete name.

### Technologies Used
- Java
- MySQL
- JDBC
- Maven
- IntelliJ IDEA

### Database Structure
The project uses a MySQL table named students with the following columns:
id:  Student's unique identifier 
name: Student's name 
age: Student's age 
department: Student's department
emaiL: Student's email address

### What I learned after doing this Project 
- Understand Java database connectivity using JDBC.
- Perform CRUD operations with MySQL.
- Use Statement and PreparedStatement to execute SQL queries.
- Retrieve database records using ResultSet.
